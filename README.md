# WEB-SERVER
Интернет-магазин для игрового сайта "MY-RELAX" с ИИ-Ассистентом.
На базе фреймворка Django с подключением PostgreSQL.


## Запуск проекта
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` в корне проекта по шаблону [.env.example](.env.example).
3. Настройте доступ к ИИ-Ассистенту, получив ключ на http://developers.sber.ru.
4. Настройте подключение к PostgreSQL.
5. Примените миграции базы данных: `python manage.py migrate`
6. Запустите локальный сервер: `python manage.py runserver`
7. Откройте проект в браузере: http://127.0.0.1:8085/


## Функционал приложения
* **Интерфейс и навигация:**
  * фиксированное боковое меню;
  * подсветка активной страницы;
  * баланс пользователя с тестовым пополнением счёта;
  * единый базовый шаблон и подшаблон главного меню.
* **Главная страница с каталогом товаров:**
  * быстрый переход к разделам категорий;
  * вывод списка товаров из базы данных PostgreSQL;
  * обрезка описания до 100 символов;
  * постраничная пагинация (AJAX без перезагрузки);
  * добавление товаров:
    * форма создания нового товара;
    * загрузка изображения;
    * валидация данных:
      * проверка обязательных полей;
      * числового формата цены;
      * типа загружаемого файла.
* **Карточка товара:**
  * страница подробной информации о товаре.
* **Контакты и обратная связь:**
  * вывод контактной информации из базы данных;
  * форма обратной связи с защитой CSRF.
* **Умный ИИ-Ассистент:**
  * интеграция консультанта на базе GigaChat API:
    * навигация по сайту;
    * баланс пользователя;
    * состав корзины;
    * история покупок.
  * Сохранение и очистка истории чата.
