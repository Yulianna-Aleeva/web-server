# WEB-SERVER
Интернет-магазин для игрового сайта "MY-RELAX" с ИИ-Ассистентом.

## Запуск
1. Установить зависимости: `pip install -r requirements.txt`
2. Для настройки доступа к ИИ-Ассистенту, создайте файл `.env` в корне проекта:  
   GIGACHAT_CREDENTIALS={ваш_ключ_Base64}  
   (ключ получить на http://developers.sber.ru)
3. Запустить: `python main.py`
4. Открыть: http://localhost:8085

## Django
1. Установите зависимости: `pip install django`
2. Запустите локальный сервер: `python manage.py runserver`
3. Откройте проект в браузере: http://127.0.0.1:8000/

## Сброс данных
Чтобы "обнулить" данные (хранятся локально в вашем браузере):
1. В браузере нажмите F12.
2. Откройте вкладку "Console"
3. Вставьте `localStorage.clear(); location.reload();`
4. Нажмите Enter.

## Функционал приложения
* **Интерфейс и навигация:**
  * Фиксированное боковое меню;
  * Подсветка активной страницы;
  * ИИ-Ассистент (GigaChat Api);
  * Баланс пользователя;
  * Пополнение счёта (тестовое).
* **Главная страница:**
  * переход сразу на начало разделов.
* **Категория ("Каталог товаров"):**
  * Удобное разделение на три основные категории:
    * игровая валюта «Печеньки»;
    * подсказки для игр;
    * реальные реплики настольных игр.
* **Умный ИИ-Ассистент:**
  * Консультант на базе GigaChat API:
    * навигация по сайту;
    * баланс пользователя;
    * состав корзины;
    * история покупок.
  * Сохранение чата.
  * Очищение чата.
* **Система двойного баланса (в левом меню сайта):**
  * Раздельный учет счета:
    * внутриигровые печеньки;
    * рубли;
  * Возможность моментального тестового пополнения.
* **Корзина для покупок:**
  * добавление товаров из раздела "Реплики игр";
  * подсчёт итоговой стоимости;
  * изменение количества элементов;
  * пересчет общей стоимости;
  * оформление заказов.
* **История заказов и инвентарь:**
  * Наглядная таблица всех совершенных покупок:
    * статусы;
    * цветная кодировка.
* **Форма контактов:**
  * Отправка данных:
    * Имя;
    * Email;
    * Сообщение.
  * Сохранение в файл [messages.txt](messages.txt) на сервере;
  * Страница успеха с таймером возврата на Главную.
* **Локальное хранение данных (в localStorage браузера):**
  * Работа без тяжелых баз данных:
    * баланс;
    * корзина;
    * история чата.
