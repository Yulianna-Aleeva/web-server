# WEB-SERVER
Интернет-магазин товаров для отдыха "MY-RELAX" с ИИ-Ассистентом.
На базе фреймворка Django с подключением PostgreSQL.


## Запуск проекта
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` в корне проекта по шаблону [.env.example](.env.example).
3. Настройте доступы к базе данных PostgreSQL, почтовому серверу (SMTP) и GigaChat API.
4. Примените миграции базы данных: `python manage.py migrate`
5. Запустите локальный сервер: `python manage.py runserver`
6. Откройте проект в браузере: http://127.0.0.1:8085/


## Функционал приложения
* **Интерфейс и навигация:**
  * фиксированное боковое меню с подсветкой активного раздела;
  * единый базовый шаблон и подшаблон главного меню.
* **Главная страница:**
  * вывод доступных товаров из базы данных PostgreSQL с постраничной пагинацией;
  * быстрый переход в каталог с фильтрацией по категориям;
  * карточка товара с подробной информацией.
* **Каталог товаров:**
  * полный каталог с фильтрацией по категориям, с поиском, сортировкой и пагинацией;
  * создание, просмотр, редактирование и удаление товаров с загрузкой изображений и валидацией данных.
* **Блог магазина:**
  * создание, редактирование и удаление записей блога;
  * вывод опубликованных записей с автоматическим счётчиком просмотров;
  * отправка поздравительного письма при достижении статьёй 100 просмотров.
* **Контакты:**
  * форма обратной связи с сохранением обращений в базу данных.
* **Умный ИИ-Ассистент:**
  * консультант магазина на базе GigaChat API с сохранением и очисткой истории чата.
* **Авторизация:**
  * регистрация с отправкой приветственного письма;
  * авторизация по email и редактирование профиля.
* **Права доступа:**
  * ограничение доступа к карточкам товаров и управлению контентом для неавторизованных пользователей.
